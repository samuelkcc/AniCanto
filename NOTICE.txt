BUILD PATH NORMALISATION
New release Rust helpers are compiled with anonymous build paths. Retained
native C/C++ tools have only diagnostic source-file strings normalised in
read-only data; executable instruction sections are verified unchanged.
Original notices are retained. See licenses/build-path-remapping.json and
scripts/sanitize_build_paths.py for the transformation and provenance.

NATIVE TOOLS AND PYTHON DEPENDENCIES
FFmpeg with GPL codecs and GPL/LGPL/MPL dependencies require their respective
notices and, where applicable, matching corresponding source/build materials.
The source manifests identify exact versions; a manifest alone does not replace
the obligation to supply the required source when distributing covered binaries.
DiffQ and Distance were unused declared dependencies of the selected audio
separation and GPT phonemization paths. New runtime locks and bundled wheels
omit them. Their upstream legal audit evidence is retained, explicitly marked
not bundled; this does not erase notices for an older installed runtime that
still contains those packages. No third-party licence is waived or replaced.
CUDA and Microsoft redistributables retain
their respective vendor terms. Refer to the packaged component inventory and
licenses/ for full third-party notices.
