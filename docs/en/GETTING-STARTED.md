# Subtitle import guide

[← AniCanto](../../README.md)

1. Download and open the app, then prepare the models and runtimes. Initial setup needs internet access.
2. Add videos and choose Cantonese, Mandarin, English or a combination. For external subtitles, use **Subtitle source → Import subtitle file** above the preview (SRT / ASS / SSA / VTT).
3. Start processing and play the finished movie. Use the review report to compare original, separated and generated speech, retake a line or select an earlier recording, then export another version.

Subtitle import attaches to the selected video. Automatic selection checks a matching external file, then embedded text tracks, then screen OCR. You can choose audio-only in Expert mode. A running or paused job retains its saved subtitle source; change it for a new conversion. Removing the association leaves the original subtitle file intact. Image subtitles are not guaranteed to work as text tracks. Interface language does not add another dubbing language.
