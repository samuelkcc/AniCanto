# Voice models

**Full Drama 3 is the preferred voice model for Hong Kong Cantonese.** Qwen 3.5 handles translation. Other available engines include GPT-SoVITS V2 Pro Plus / V4 and official CosyVoice 3; availability depends on the platform and installed runtime.

Mac uses full Drama 3 4-bit MLX on Apple Silicon GPU / unified memory. Windows uses full Drama 3 GGUF Q2 on the **CPU and system RAM**; a dedicated graphics card does not accelerate this adapter. Drama3-small is retired and is not the recommended lower-memory alternative.

See the four-language homepages for current hardware guidance and the in-app model centre for download size, memory estimates, installation status and model terms. Existing recordings remain available when you change the active model.
