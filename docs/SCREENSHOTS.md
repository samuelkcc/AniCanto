# Interface gallery

[← AniCanto](../README.md)

The app is designed primarily in **Hong Kong Traditional Chinese**, with an **English interface** for English speakers interested in Cantonese. This gallery presents English screenshots first. Traditional Chinese views are available in the expandable section below.

Real application screens use original demo dialogue and illustrative model/project states. These are interface illustrations, not full-conversion or performance evidence. Click an image to inspect it at full size.
