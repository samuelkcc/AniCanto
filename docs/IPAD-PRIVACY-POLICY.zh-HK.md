# AniCanto iPad 私隱政策

[繁體中文](IPAD-PRIVACY-POLICY.zh-HK.md) · [简体中文](IPAD-PRIVACY-POLICY.zh-CN.md) · [English](IPAD-PRIVACY-POLICY.md) · [日本語](IPAD-PRIVACY-POLICY.ja.md)

[技術支援](../SUPPORT.zh-HK.md) · [AniCanto 主頁](../README.zh-HK.md)

此政策適用於 AniCanto iPad 版，由 SCKC 提供；不描述桌面版或 GitHub 網站本身的資料處理。

## 繁體中文

### 裝置內處理

影片辨識、翻譯、配音及字幕處理均在你的 iPad 上進行。AniCanto 不會將你的影片、錄音、字幕、文字稿或生成內容上載到開發者或第三方 AI 伺服器。

### 網絡連線

下載或修復模型需要連接模型檔案供應商；對方會接收提供下載所需的連線資料，例如 IP 位址。這些下載不包含你的影片、聲音或文字稿。Apple 系統資源及 App Store 購買／恢復由 Apple 處理。

### 檔案、分享與備份

匯入副本、工作進度、錄音及成品保存在 App 內。只有在你主動使用分享或另存功能時，內容才會交給你選擇的 App 或檔案供應商，例如 iCloud Drive、Google Drive 或 OneDrive。iPadOS 備份及雲端服務依照你的系統及帳戶設定運作。

### 記錄與刪除

AniCanto 不包含廣告追蹤或使用分析 SDK，亦不會自動向開發者傳送使用記錄。執行紀錄保存在裝置內；你可自行決定是否匯出或分享。你可在影片列表、成品庫及模型管理刪除對應內容；已另存到其他位置的副本需在該位置另行刪除。

### 聯絡與更新

如有一般私隱問題，可透過[技術支援頁](../SUPPORT.zh-HK.md#聯絡-sckc)所列的 GitHub Issues 聯絡 SCKC。Issue 為公開內容，請只概括描述問題，不要提交個人資料、私人影片、錄音、文字稿或購買收據。你主動發表的支援內容由 GitHub 託管，按 [GitHub 私隱聲明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)及其帳戶／內容管理設定處理；這與 App 內的本機檔案分開。如資料處理方式有更改，本政策亦會更新。

生效日期：2026 年 10 月 23 日
