# AniCanto iPad 隐私政策

[繁體中文](IPAD-PRIVACY-POLICY.zh-HK.md) · **简体中文** · [English](IPAD-PRIVACY-POLICY.md) · [日本語](IPAD-PRIVACY-POLICY.ja.md)

[技术支持](../SUPPORT.zh-CN.md) · [AniCanto 主页](../README.zh-CN.md)

生效日期：2026 年 10 月 23 日。本政策适用于 SCKC 提供的 AniCanto iPad 版，不描述桌面版或 GitHub 网站自身的数据处理。

## 简体中文

### 设备内处理

视频识别、翻译、配音及字幕处理均在你的 iPad 上进行。AniCanto 不会将你的视频、录音、字幕、文字稿或生成内容上传到开发者或第三方 AI 服务器。

### 网络连接

下载或修复模型需要连接模型文件提供商；对方会接收提供下载所需的连接信息，例如 IP 地址。这些下载不包含你的视频、声音或文字稿。Apple 系统资源及 App Store 购买／恢复由 Apple 处理。

### 文件、分享与备份

导入副本、任务进度、录音和成品保存在应用内。只有在你主动使用分享或另存功能时，内容才会交给你选择的应用或文件提供商，例如 iCloud Drive、Google Drive 或 OneDrive。iPadOS 备份和云端服务按照你的系统及账号设置运行。

### 日志与删除

AniCanto 不包含广告追踪或使用分析 SDK，也不会自动向开发者发送使用日志。运行日志保存在设备内；你可以自行决定是否导出或分享。你可以在视频列表、成品库和模型管理中删除对应内容；已另存到其他位置的副本需要在该位置另行删除。

### 联系与更新

如有一般隐私问题，可通过[技术支持页](../SUPPORT.zh-CN.md#联系-sckc)列出的 GitHub Issues 联系 SCKC。Issue 为公开内容，请只概括描述问题，不要提交个人信息、私人视频、录音、文字稿或购买收据。你主动发布的支持内容由 GitHub 托管，按照 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)及其账号／内容管理设置处理；这与应用内的本地文件分开。如数据处理方式有变更，本政策也会更新。
