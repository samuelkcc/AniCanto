# 外掛字幕操作說明（0.24.57）

1. 加入影片並選中正確影片。
2. 預覽上方按「字幕來源」→「匯入字幕檔」，選擇 SRT、ASS、SSA 或 VTT。
3. 核對顯示檔名，再開始新轉換。明確匯入優先於自動偵測；未指定時依次使用同名外掛、內嵌文字字幕及 OCR。
4. 同一面板可以更換檔案或移除配對；移除不會刪除原檔。
5. 轉換中／已暫停任務鎖定提交時的字幕來源；暫停不是解鎖。完成目前版本後先可為新轉換選擇另一份字幕。
6. 原聲仍為翻譯主要依據，字幕提供人名及語意參考；不保證逐字照讀中文字幕。原裝字幕時間與配音時間分開保存。

此功能需要配對影片，不是純字幕生成音檔入口。處理完成前保留外掛字幕在可讀取位置；檔案移動後要重新選取。工作說明書／Help Centre 的「翻譯來源與字幕」已同步英、香港繁體、簡體及日文。
