## 日本語

### 端末内での処理

動画の音声認識、翻訳、音声生成、字幕処理は、お使いの iPad 上で行われます。AniCanto は、動画、録音、字幕、台本、生成したコンテンツを、開発者や第三者の AI サーバーにアップロードしません。

### ネットワーク接続

モデルのダウンロードや修復では、モデルファイルの提供元に接続します。提供元は、ダウンロードの配信に必要な IP アドレスなどの接続情報を受け取ります。これらのダウンロードに、あなたの動画、音声、台本は含まれません。Apple のシステムリソースと App Store での購入・復元は Apple が処理します。

### ファイル、共有、バックアップ

読み込んだファイルのコピー、処理の進捗、録音、完成作品はアプリ内に保存されます。共有やコピーの保存を自分で選んだ場合に限り、コンテンツは選択したアプリやファイル提供元（iCloud Drive、Google Drive、OneDrive など）に渡されます。iPadOS のバックアップとクラウドサービスは、システムとアカウントの設定に従って動作します。

### ログと削除

AniCanto には広告追跡や利用状況分析の SDK は含まれておらず、利用ログを開発者に自動送信しません。処理ログは端末内に保存され、書き出しや共有を行うかどうかは利用者が選べます。動画一覧、完成作品ライブラリ、モデル管理で、それぞれのデータを削除できます。他の場所に保存したコピーは、その保存先で別途削除する必要があります。

### お問い合わせと更新

プライバシーに関する一般的なご質問は、[サポートページ](../SUPPORT.ja.md#お問い合わせ)に記載の GitHub Issues から SCKC にお問い合わせください。Issue は公開されます。個人情報、私的な動画、録音、台本、購入の領収書は投稿せず、質問の概要だけをご記入ください。自分で投稿したサポート内容は GitHub 上に保存され、[GitHub のプライバシーに関する声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)とアカウント・コンテンツ管理の設定に従って扱われます。これはアプリ内のローカルファイルとは別の取り扱いです。データの取り扱いが変わった場合、本ポリシーも更新します。
