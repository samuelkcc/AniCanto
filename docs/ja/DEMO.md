# 元のデモを変換して、声を比較する

[← AniCanto](../../README.ja.md)

**3分のオリジナル日本語サンプル**をダウンロードし、AniCanto に読み込んで広東語・英語への変換を試せます。絵、音楽、合成音声はこのプロジェクト用に制作され、市販アニメの映像やプロの声優の録音は含みません。

比較用の **Mac Drama 3 動画**は広東語が標準で、英語・日本語の音声も保持しています。対応プレーヤーで切り替えられます。広東語・英語の台詞は編集してから生成しており、**未編集のワンクリック翻訳ベンチマークではありません**。iPad CosyVoice の変換結果でもありません。4種類の画面言語版は同じ日本語音声を使用します。

**[デモ一式をダウンロード](https://github.com/samuelkcc/AniCanto/releases/download/v0.24.63-beta/AniCanto-demo-kit-v7.zip)** — 4種類の画面言語の元日本語MP4、Mac Drama 3 比較動画、対応する日本語原文字幕を含みます。

1. 元の MP4 と同名の `.srt`、またはデモ一式をダウンロードします。MP4 と SRT は同じフォルダーに保存してください。
2. 元動画を AniCanto に追加し、必要なら字幕ソースで付属の日本語 SRT を選びます。広東語・英語・両方を選んで変換します。
3. 別の Mac Drama 3 動画と比較します。比較用は台詞を編集し独自の吹き替え時間を持つため、新しい翻訳・生成と異なる場合があります。対応プレーヤーで広東語・英語・日本語の音声を切り替えられます。

元の日本語も Mac で作成した合成音声です。比較動画はプロの俳優の録音、新しい変換への品質保証、iPad CosyVoice の出力ではありません。元動画は180秒・1280×720、Mac 比較動画は広東語が標準です。Built with Fish Audio。生成にはインストール済みの Fish Audio Community License 1.0 モデルを使用し、重みや個人の動画は配布しません。
