# 字幕読み込みガイド

[← AniCanto](../../README.ja.md)

1. アプリをダウンロードして開き、モデルと実行環境を準備します。初期設定にはインターネット接続が必要です。
2. 動画を追加し、広東語・英語・両方から選択。外部字幕はプレビュー上部の **字幕ソース → 字幕ファイルを読み込む**（SRT／ASS／SSA／VTT）から追加できます。
3. 処理を開始して完成動画を再生。気になる箇所は校正レポートで元音声・分離音声・吹き替えを比較し、再生成または過去の録音を選んで別バージョンを書き出せます。

字幕は選択中の動画に関連付けられます。自動選択では外部字幕、内蔵テキスト字幕、画面 OCR の順に確認します。エキスパートモードでは音声のみも選べます。実行中・一時停止中の処理は保存済みの字幕ソースを保持します。変更は新しい変換に適用してください。関連付けを外しても字幕ファイルは削除されません。画像字幕をテキストとして読めるとは限りません。UI の言語を変えても吹き替え言語は増えません。
