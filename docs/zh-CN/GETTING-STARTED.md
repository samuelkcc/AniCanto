# 字幕导入说明

[← AniCanto](../../README.zh-CN.md)

1. 下载并打开应用，准备模型和运行环境；首次设置需要网络。
2. 添加视频，选择粤语、英语或双语。外挂字幕入口：预览上方 **字幕来源 → 导入字幕文件**（SRT／ASS／SSA／VTT）。
3. 开始处理并播放成品。如有疑问，在校对报告中逐句比较原声、分离声音和配音，重新生成或选择旧录音，再导出另一个版本。

字幕只绑定所选视频。自动选择依次检查匹配的外挂文件、内置文字字幕和画面 OCR。专家模式也可选择只用音频。运行中或暂停的任务保留已保存的字幕来源；更换来源请用于新转换。解除绑定不会删除原字幕文件。图片字幕不保证能作为文字轨读取。界面语言不代表新增配音语言。
