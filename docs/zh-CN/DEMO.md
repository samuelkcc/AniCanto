# 下载测试原片，听配音成品作比较

[← AniCanto](../../README.zh-CN.md)

下载 **3 分钟日语原创测试片**，放入 AniCanto，自己试转广东话或者英语。画面、音乐和合成声线均为本项目准备，不包含商业动画片段或专业配音员录音。

另提供 **Mac Drama 3 配音成品**，默认广东话，保留英语和日语音轨，可在兼容播放器切换。广东话和英语台词经过编辑再生成，用于比较声音效果，**不是未经校订的一键翻译成绩**，也不是 iPad CosyVoice 转换结果。四种画面语言版本使用相同的日语原声。

**[下载完整测试套装](https://github.com/samuelkcc/AniCanto/releases/download/v0.24.63-beta/AniCanto-demo-kit-v7.zip)** — 包含四种画面语言的日语原片、Mac Drama 3 对比成品，以及与原片配对的日语原文字幕。

1. 下载一条原片 MP4 和配对 `.srt`，或解压完整套装；MP4 和 SRT 保持同名并放在同一文件夹。
2. 将原片加入 AniCanto；如有需要在「字幕来源」选用所提供的日语 SRT，选择广东话、英语或双语后开始处理。
3. 用另一条 Mac Drama 3 成品比较。参考成品使用编辑过的台词及自己的配音时间，所以新转换结果可能不同；用支持音轨选择的播放器切换广东话、英语和日语。

日语原声亦是在 Mac 准备的合成表演；对比成品不是专业演员录音，不保证新转换效果相同，也不是 iPad CosyVoice 成品。原片 180 秒、1280×720，Mac 对比片默认广东话。Built with Fish Audio；Drama 3 使用已安装、按 Fish Audio Community License 1.0 提供的模型，套装不包含权重或私人影片。
