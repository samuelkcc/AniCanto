# Desktop 0.24.86 / build 239

New jobs use the shared `anicanto-recovery-workflow-2` requirements. The current operating guide is [DESKTOP-WORKFLOW.md](DESKTOP-WORKFLOW.md); installation evidence belongs in the private development handover, not in this requirements note.

- Selected **Subtitles > speech** translates only authored subtitles. Unsubtitled gaps retain source audio and are excluded from missing-dub repair. Authored text missed by ASR keeps an explicitly labelled subtitle-display clock. Older jobs retain their frozen source policy.
- Balanced is the default. Performance / Balanced / Quality have 1 / 1 / 3 initial attempts and separate, persistent stage allowances. Content listening and automatic recovery share 60 / 180 / 600 seconds per film, with the final quarter reserved for installed system target-language voices. An in-flight operation may finish; the next item or chunk cannot start after its deadline. Full AI frame analysis is a separate optional switch; it does not launch an unbudgeted second whole-film audio review at export.
- Confirmed wrong speech proceeds through bounded target-language fallback. Uncertain ASR, spelling and accent labels remain warnings, never certification. A confirmed wrong first take is not revived merely because it is audible.
- The final target-language fallback uses only compatible installed Mac system / Windows SAPI voices, at most two attempts per cue. It is disclosed before starting, can be disabled and does not claim character cloning. Original audio is last, except an explicit Original audio failure policy. Ordinary model/native failures still reach finalization; corrupt media or persistent I/O/encoding failures remain honest errors.
- Shortening requires a measured overrun and faithful text review. Legacy pre-generation character-budget fragment rewriting is bypassed for the new policy. Each revised text receives a new cache identity, while used attempt counters remain spent.
- Encode, caption packaging and validation get one durable retry. A validated audio checkpoint supports final-only resume without TTS. Empty target-caption content does not create a fabricated subtitle or an invalid empty subtitle input. Original-only output explicitly distinguishes preserved source from completed target-language dubbing.
- Explicit new conversion or dubbing child versions get fresh execution ledgers; ordinary resume does not. Parent source identity, scripts, takes and versions remain intact. Manual audition, cancellation and selected recordings are protected.
- English script generation fixes an outer-prompt scope error. The allowlisted desktop source exporter fixes a malformed document-name literal and continues to exclude private mobile implementation and validation.

Acceptance includes 350 focused Python tests, five four-language/browser mode cases, six native mode/switch combinations, packaged subtitle operations, 18 actual synthetic MP4 exports across modes/failure policies/full-AI settings, final-only resume with TTS forbidden, and three subtitle-gap source-preservation exports. A real installed Mac Hong Kong system voice was sampled separately. These are bounded workflow checks, not Windows device inference, whole-film intelligibility, accent or performance certification.
