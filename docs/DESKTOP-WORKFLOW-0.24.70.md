## Implemented desktop workflow

1. **Generic original performances**: shared detection applies to any film/role/title. Original/stem classification is independent. Acoustic evidence around dialogue tails is checked in at most 16 bounded regions, at actual source times, with cache identities including backend/window profile and audio SHA. Existing lexical speech exclusions remain. Laughs, cries, screams, breaths and sighs are not inferred from transcript vowel spelling or an ASR gap. Spoken calls such as 助けて / Help / 救命 remain lexical translation targets. Uncertain sounds get a separate listening report; explicit saved source-interval choices are editorial overrides, never AI quality passes.
2. **Names / techniques**: project source, Cantonese, Mandarin and English terms can be edited and locked. Explicit keep-original applies to the whole matching source line, not just a name. User rules override automatic suggestions, guide translation, and mismatches enter the report. Saving terms does not silently overwrite recordings; removing a preservation rule removes its derived flag. Normal names remain translated unless deliberately kept.
3. **Audio language / stream**: samples the actual selected audio rather than trusting file labels. Metadata/detection disagreement is shown. A user can choose the real source language and stream separately from subtitle language. The choice is frozen for conversion. Missing evidence does not silently certify Japanese.
4. **Subtitle evidence**: external bytes are copied per submitted request with SHA-256. Paused resume verifies frozen content, not the mutable source path. Normalised external/embedded subtitle evidence also gets a source-clock SHA receipt. Cached resume and editorial rendering validate an existing receipt. Legacy projects without a receipt are not retroactively certified.
5. **Bounded generation**: one persisted exact-input ledger across automatic stages (text, reference audio SHA/transcript, effective parameters, engine/model, target language and delivery style). At most three automatic submissions including the first. Seed changes alone do not reset it. Specific deterministic input/semantic-window failures stop identical resubmission. Corrupt ledgers cannot reset the budget. A deliberate new take / explicit reported-line retry / regenerate-all is a new manual budget. New versions do not write generation budgets into donor folders. First audible takes remain; measured overlong lines may still be shortened locally.
6. **Actionable review**: source/stem/generated/failed/selected recordings, measurements, exact-input counts and permanent failures are distinguishable. Performance uncertainty is separate from missing TTS. Locked-term mismatches require script review, not blind automatic TTS retries. Saved interval choices apply on a new export.
7. **Update menu** under Produce: selected line, all voices, add track, replace track, merge saved recordings, or full reanalysis. Append/replace use exact language/engine pairs, not a Cartesian expansion. Retained reports/audio are SHA-bound, old captions are not rewritten, prior movies remain. Reanalysis gets a fresh analysis identity. This is explicit user work, not an automatic restart of a completed film.
8. **Preview player**: ±10s, fullscreen with controls that hide while playing, keyboard seeking, volume/mute, audio-track selection, captions and on-demand hover thumbnails. The chosen audio stream is actually mapped into its preview; switching retains playhead/volume. Thumbnail work is outside the conversion-state lock. Progress explains that overall totals can include saved work.

Four interface languages and the in-app manual include the new workflow. Reading / learning modes and optional screensaver/OCR-default changes remain outside desktop scope.
