## What is in this repository

At this preparation stage, the repository contains the Traditional Chinese and English project introductions, language-matched guides and original demonstration screenshots/cover. It does not contain application binaries, model weights, user media or the complete application source tree. Public downloads and full source publication remain pending.

The original application code is MIT, copyright © 2026 SCKC. Preserve [LICENSE](../LICENSE). A root MIT licence does not relicense third-party dependencies or model weights.

## Models and tools

**Built with Fish Audio.** Drama 3 keeps the [Fish Audio Community License](https://huggingface.co/fishaudio/drama-3/blob/main/LICENSE), including its attribution and applicable usage/commercial/hosted-service conditions. Consult the exact model terms before using or distributing model materials. Optional community conversions are not automatically covered merely because their base model has a licence.

The eleven conversions without confirmed evidence have been removed from the shipping download catalogues. Original audit records may mention them for traceability; they are not download offers. Official native CosyVoice 3 is offered only on Windows NVIDIA/CUDA. Mac MLX CosyVoice 3 is not offered.

Binary releases will need their exact third-party notices, corresponding source/build materials and release checks. This documentation-only preparation is not a substitute for those obligations. See the [FFmpeg distribution guidance](https://ffmpeg.org/legal.html).
