# 下載測試原片，聽返配音成品比較

[← AniCanto](../../README.zh-HK.md)

下載 **3 分鐘日文原創測試片**，放入 AniCanto，自己試轉廣東話或者英文。畫面、音樂同合成聲線都為呢個計劃準備，唔包含商業動畫片段或專業配音員錄音。

另外提供 **Mac Drama 3 配音成品**，預設廣東話，保留英文同日文音軌，可喺兼容播放器切換。廣東話同英文台詞經過編修再生成，用嚟比較聲音效果，**唔係未經校訂嘅一鍵翻譯成績**，亦唔係 iPad CosyVoice 轉換結果。四種畫面語言版本用同一套日文原聲。

**[下載完整測試套裝](https://github.com/samuelkcc/AniCanto/releases/download/v0.24.63-beta/AniCanto-demo-kit-v7.zip)** — 包括四種畫面語言嘅日文原片、Mac Drama 3 比較成品，以及同原片配對嘅日文原文字幕。

1. 下載一條原片 MP4 同配對 `.srt`，或解壓完整套裝；MP4 同 SRT 保持同名並放喺同一資料夾。
2. 將原片加入 AniCanto；如有需要喺「字幕來源」揀提供嘅日文 SRT，揀廣東話、英文或雙語後開始處理。
3. 用另一條 Mac Drama 3 成品比較。參考成品用咗編修台詞同自己嘅配音時間，所以新轉換結果可以唔同；用支援音軌選擇嘅播放器切換廣東話、英文同日文。

日文原聲亦係喺 Mac 準備嘅合成演出；比較成品唔係專業演員錄音、唔保證新轉換同樣效果，亦唔係 iPad CosyVoice 成品。原片 180 秒、1280×720，Mac 比較片預設廣東話。Built with Fish Audio；Drama 3 使用已安裝、按 Fish Audio Community License 1.0 提供嘅模型，套裝唔包含權重或私人影片。
