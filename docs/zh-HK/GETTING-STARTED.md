# 字幕匯入說明

[← AniCanto](../../README.zh-HK.md)

1. 下載並開啟 App，完成模型同執行環境準備；首次設定需要網絡。
2. 加入影片，揀廣東話、普通話、英文或組合。要用外掛字幕：預覽上方 **字幕來源 → 匯入字幕檔**（SRT／ASS／SSA／VTT）。
3. 開始處理；完成後播放成品。有疑點可打開校對報告，逐句聽原聲、分離聲音同配音，再重錄或改揀錄音，輸出另一個版本。

字幕匯入只套用到所選影片。自動選擇先搵配對外掛檔，再讀內置文字字幕，最後嘗試畫面 OCR。專家模式亦可揀只用聲音。處理中或已暫停嘅工作會沿用已保存嘅字幕來源；要改來源請用新轉換。解除配對唔會刪除原字幕檔。圖片字幕唔保證可以當文字軌讀取。介面語言唔代表新增配音語言。
