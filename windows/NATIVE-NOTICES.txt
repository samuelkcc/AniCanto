Desktop/runtime dependencies are downloaded separately. About reads their
installed distribution metadata and original notices, grouping equal name /
version entries across isolated environments without discarding notices.
Qt/PySide6, PyAV/FFmpeg, Torch and voice-engine dependencies retain their own
terms. Exact pinned environments are recorded in requirements-*.lock.

Separately downloaded Windows tools are pinned in native-tools.json, including
FFmpeg and Ollama. Their extracted distributions retain their original files
and notices. Native model formats, repository revisions, filenames, sizes and
SHA-256 values are recorded in native-models.json and shared model catalogs.
Source revisions for optional GPT/Cosy engines are pinned in shared sources
and models.json. Fonts and local reference recordings retain the notices in
shared/fonts/ and shared/natural-voices/.

This local test build has not completed the public binary redistribution and
corresponding-source review. No GitHub release is performed by packaging it.
